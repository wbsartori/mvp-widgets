
### Clone do projeto
```bash
  git clone git@github.com:wbsartori/mvp-widgets.git
```

### Iniciar o projeto com docker
```bash
  docker compose up -d --build
```

### Instalar dependências

```bash
docker compose run --rm php-fpm composer install
```

### Abra o navegador 

```bash
http://localhost:8000
```
